# F01 - Speedtest Frame Feature

## Summary
Add a new project showcase entry under the About Me section that embeds the Speedtest app in an HTML frame and clearly marks it as one of the author's projects.

## Requirements
- Render an HTML frame that loads the URL:
  https://ason-speedtest-670514734786.europe-west1.run.app/
- Place the feature under the About Me section.
- Include a wrapper component that visually identifies the embedded experience as one of the author's projects.

## Functional behavior
- The frame should be displayed as a prominent project card or section within the About Me area.
- The wrapper should provide context such as a title, short description, and visual styling to distinguish it from ordinary embedded content.
- The embedded app should remain visible and interactive inside the frame.

## UI notes
- Use a responsive layout so the frame scales well on desktop and mobile.
- Keep the surrounding wrapper consistent with the existing portfolio styling.
- Ensure the frame is accessible and does not break the page flow.

## Acceptance criteria
- The Speedtest app is embedded via an HTML iframe.
- The feature appears in the About Me section.
- The wrapper clearly communicates that this is a personal project.
